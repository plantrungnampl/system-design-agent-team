# V1 Foundation and First Vertical Slice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the smallest operational V1 slice that initializes a project and enforces `Project Intake -> Business Analyst -> Requirements Reviewer -> Requirements Approval -> Product Owner Handover` with durable YAML state, plugin blocking, independent review, traceability checks, and a usable CLI.

**Architecture:** Use a TypeScript npm workspace with small packages matching the approved domain boundaries. Git-backed YAML files remain authoritative; pure workflow functions decide transitions, `ProjectStore` performs contained atomic writes, and the CLI composes those packages. The Codex adapter prepares a bounded dispatch bundle but does not pretend to invoke unavailable plugins.

**Tech Stack:** Node.js 20+, TypeScript, npm workspaces, Node's built-in test runner, `zod`, and `yaml`.

## Global Constraints

- English is the canonical artifact and agent-to-agent language.
- Markdown and YAML project artifacts are authoritative; derived files are rebuildable.
- An artifact author cannot approve or review that artifact in the same execution.
- Only the workflow engine may commit official state transitions.
- Required plugin status `unknown`, `unavailable`, or `verification_failed` blocks strict dispatch.
- Human approval is mandatory for final requirements at G2.
- No implementation claim is accepted without reproducible test or execution evidence.
- All filesystem writes must remain inside the selected project root.
- Node.js 20 is the minimum runtime; do not depend on Node 22+ APIs.
- Do not implement V2 parallel orchestration, V3 Python runtime, production deployment, or a dashboard in this plan.

## Scope Split

The approved specification contains independent subsystems too large for one safe change. This plan implements the framework foundation and its first END2END vertical slice. Later plans will extend the same contracts with the full artifact catalogue, SQLite cache, all role manifests, all three complete workflows, upgrades, and the remaining END2END fixtures.

```ts
const transitions: Record<PhaseStatus, readonly PhaseStatus[]> = {
  not_started: ["ready"], ready: ["in_progress"], in_progress: ["artifact_validation", "blocked", "failed", "cancelled"],
  artifact_validation: ["under_review", "revision_required", "blocked"],
  under_review: ["revision_required", "awaiting_approval", "blocked"],
  revision_required: ["in_progress", "blocked", "cancelled"],
  awaiting_approval: ["approved", "revision_required", "blocked"], approved: ["handed_over", "superseded"],
  handed_over: ["superseded"], blocked: ["ready", "cancelled"], failed: ["ready", "cancelled"],
  cancelled: [], superseded: [],
};

export function transitionPhase(state: WorkflowState, workflow: WorkflowDefinition, request: TransitionRequest): WorkflowState {
  if (state.completed_operations.includes(request.operation_id)) return state;
  const current = state.phases[request.phase];
  if (!current || !transitions[current.status].includes(request.to)) throw new WorkflowError("INVALID_TRANSITION");
  if (request.to === "ready") assertDependenciesApproved(state, workflow, request.phase);
  return {
    ...state,
    state_version: state.state_version + 1,
    current_phase: request.phase,
    completed_operations: [...state.completed_operations, request.operation_id],
    phases: { ...state.phases, [request.phase]: { ...current, status: request.to } },
  };
}
```

```ts
function contained(root: string, relativePath: string): string {
  const target = resolve(root, relativePath);
  const relation = relative(root, target);
  if (relation.startsWith("..") || isAbsolute(relation)) throw new ProjectStoreError("PATH_OUTSIDE_PROJECT");
  return target;
}

async function atomicWrite(path: string, content: string): Promise<void> {
  await mkdir(dirname(path), { recursive: true });
  const temporary = `${path}.${randomUUID()}.tmp`;
  await writeFile(temporary, content, { encoding: "utf8", flag: "wx" });
  await rename(temporary, path);
}
```
